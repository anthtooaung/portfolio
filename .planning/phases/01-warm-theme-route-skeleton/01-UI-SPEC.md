### Gradient Refactor (THME-03)

**Current:** `.text-gradient-violet` hardcodes second color as `oklch(0.75 0.18 310)` (violet).

**New:** Both gradient stops read from CSS variables:

```css
.text-gradient-violet {
  background: linear-gradient(135deg, var(--primary), oklch(0.75 0.18 var(--gradient-hue, 75)));
  /* Alternatively, rename to .text-gradient-warm and use two var() stops */
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  background-clip: text;
}
```

**Recommended approach:** Rename to `.text-gradient-warm` and update the second stop to read from `var(--primary)` with a lighter offset. The gradient should transition from `var(--primary)` at 0% to a lighter amber (`oklch(0.78 0.12 75)`) at 100%, keeping the warm palette cohesive. Update the one reference in `HeroSection.tsx` line 30.
